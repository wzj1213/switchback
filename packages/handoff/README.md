# @omni/handoff

从会话记录生成确定性的交接材料，以及分叉对比。全部是纯函数：不读文件、不读时钟，
路径、大小、时间都由调用方量好传进来。

## 拥有什么

- `buildHandoff(thread, items)` —— 从对话记录提炼目标、要求、最后一次成功文件编辑上报、
  成功命令、人工裁决与未完成计划
- `compareRuns(a, b)` —— 比较两份运行摘要，供桌面分叉对比视图使用
- 父子分叉对比按 `forkedFromItemCount` 排除共同历史，不把分叉前的工作算成父侧独有
- `transcriptOf(...)` —— **交接用的会话转写**，尽量无损：每轮的提问、回答、推理原文、
  工具调用与完整输出、完整 diff、计划、审批、报错；每轮标注开始时间（UTC）与引擎，
  工具调用带引擎原生 id（条目上的 `nativeId`，宿主重铸 id 前记下的）
- `logFacts(content, ids)` —— 一份引擎原始记录**实际**是什么格式：JSONL / JSON / 文本、行数、
  顶层 `type` 取值与条数、已知原生 id 落在哪个字段、每行的 ISO 时间戳在哪个字段。
  从文件内容读出来，不是维护的格式说明
- `briefOf(...)` —— 换引擎后第一句话前的交接说明：此前谁跑了哪几轮、转写在哪（多少行、
  最后一轮从第几行起）、各段原始记录在哪、原始记录的格式事实。包在 `<omni-handoff>` 里
- `turnEnginesOf(events)` —— 每一轮是哪家开的（`turn.started` 上记着）；
  转写与分段优先认它，缺了才按分段开始时间推断

## 不拥有什么

- **不决定什么时候附交接说明。** 只在用户开着「换引擎自动交接」、刚换了一家、
  发出第一句话时附（时机由宿主 `handoff-note.ts` 判定，开关与落盘在桌面端主进程）。
- **不写任务、不评价、不催进度。** 交接说明只陈述事实；读不读、读多少由接手的那家定。
  这是 AGENTS.md「不往模型上下文塞 omni 写的话」唯一的例外，边界写在那里。
- **不维护各家日志的格式说明。** 厂商改格式不会通知谁；格式事实每次现读现报。
- 不读写文件系统。转写落盘、原始记录读取由桌面端主进程做。
- 不管会话的起停。那是 `@omni/host` 的事。

## 已知限制

- 文件数字只来自编辑工具最后一次成功上报，排除失败与 `inherited` 记录；
  **不是 Git 净 diff**，shell/用户编辑也不在其中。不会静默裁掉多文件上报；
  真实净差异看审核面板。
- 只取**最后一份**计划里的未完成项。计划是整份替换的，
  取历史并集会把早就删掉的条目翻出来，让接手的一家去做一件已经被否决的事。
- 摘要只用于帮助人定位差异，不能判断哪一边正确。
- 转写只有 omni 收到过的东西：引擎没以事件报出来的内容（系统提示、某些内部工具）
  只在原始记录里。轮次归属优先认 `turn.started` 上记的引擎；没有这条记录的轮次
  （接管进来的历史）才按分段开始时间推断，那时换家后第一轮可能被算在前一家名下。
- 转写来自 omni 的会话记录：单个会话记录写满 32 MB 后不再落盘，之后的轮次也就不在转写里；
  分叉出来的会话从空分段起步，跨引擎分叉不附交接说明。
- 原生 id 来自条目上的 `nativeId`，2026-09-25 起才记，更早的记录不标。有的驱动报的 id
  本身是拼出来的（例如 `序号:调用 id`），在原始记录里搜不到；`logFacts` 找不到就不报 `idPath`，
  这时只能按时间戳字段对位（`timePath`，前 20 行里至少一半带 ISO 时间才报）。
