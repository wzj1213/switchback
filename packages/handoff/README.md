# @omni/handoff

跨引擎接力（L2）的交接包。**纯函数**——从 transcript 里提炼结论。

## 拥有什么

- `buildHandoff(thread, items)` —— 从对话记录里提炼：目标、追加的要求、
  改动过的文件、成功执行过的命令、人工裁决过的事、尚未完成的计划项
- `renderHandoff(handoff, from, to)` —— 交给下一家的第一条消息

## 不拥有什么

- **不搬运原始上下文。** 各家的 session 格式互不相通，硬翻既做不对也维护不起；
  更重要的是原始上下文里绝大部分是过程噪声（试错、被拒的调用、读了一半的文件），
  换一家从头看反而更慢。交接包传的是**结论**——这也是人交接工作的方式，
  不会把自己三天的浏览记录发给同事。
- 不读文件系统。工作区的真实状态由接手的一家自己去核。
- 不管会话的起停。那是 `@omni/host` 的事。

## 已知限制

- **「已确认事实」目前只能从审批记录里推**。模型在正文里说过的结论
  （「确认这个 bug 出在 X」）提炼不出来——那需要让引擎自己产出结构化摘要，
  各家都还没有这个能力。
- 只取**最后一份**计划里的未完成项。计划是整份替换的，
  取历史并集会把早就删掉的条目翻出来，让接手的一家去做一件已经被否决的事。
- 上一家最后一段话截断到 800 字符。
- 交接质量**没有自动化衡量**。它好不好只能人看。
