# @omni/handoff

历史包名保留；当前拥有的是**纯函数运行摘要与分叉对比**，不向引擎发送任何内容。

## 拥有什么

- `buildHandoff(thread, items)` —— 从对话记录提炼目标、要求、最后一次成功文件编辑上报、
  成功命令、人工裁决与未完成计划
- `compareRuns(a, b)` —— 比较两份运行摘要，供桌面分叉对比视图使用
- 父子分叉对比按 `forkedFromItemCount` 排除共同历史，不把分叉前的工作算成父侧独有

## 不拥有什么

- **不生成提示词、不渲染交接消息，也不向任何引擎发送摘要。** 接力只切换原生会话，
  原始记录路径由 `Thread.segments` 保存并交给用户决定是否取用。
- 不读文件系统。工作区的真实状态由接手的一家自己去核。
- 不管会话的起停。那是 `@omni/host` 的事。

## 已知限制

- 文件数字只来自编辑工具最后一次成功上报，排除失败与 `inherited` 记录；
  **不是 Git 净 diff**，shell/用户编辑也不在其中。不会静默裁掉多文件上报；
  真实净差异看审核面板。
- 只取**最后一份**计划里的未完成项。计划是整份替换的，
  取历史并集会把早就删掉的条目翻出来，让接手的一家去做一件已经被否决的事。
- 摘要只用于帮助人定位差异，不能判断哪一边正确。
