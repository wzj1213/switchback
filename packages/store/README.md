# @omni/store

事件流 → 视图状态的**纯归约器**。`reduce(state, event) → state`，没有 IO、没有时钟。

**宿主和渲染层共用同一份。** 宿主持有权威状态用于断点恢复，渲染层持有视图副本用于渲染；
两边跑同一个归约器，就不会出现「宿主认为在跑、界面显示已完成」这类漂移。
这也是它不能住在 `@omni/host` 里的原因——渲染层不该为了一个纯函数把 Node 依赖打进浏览器包。

## 拥有什么

- `ViewState` —— 会话表、顺序、每个会话的 item 列表与当前轮次
- `notices` —— 引擎故障与原生一次性通知；同一会话、引擎和原生 key 的提示只留最新一条。
  故障按状态分三类抬头：`crashed`（故障）、`degraded`（能力受限）、`auth`（引擎明确要先登录，带引擎 id，
  那一家登录成功后界面据此收起）
- `reduce(state, event)` —— 唯一入口，纯函数，不可变更新
- `reduceHistory(state, threadId, events)` —— **单独补一条会话的历史**。
  先清掉这条的条目再按历史铺开：直接 `reduceAll` 的话，已经在直播的那几条
  会把更早的历史挤到后面去，转录区变成「最新的排在最前」；对应 item 反查也一起清，
  不留下列表里已经不存在的幽灵索引
- `initial()` —— 空状态
- `reduceAll` 的批量消息累加器：每条被修改的会话只复制一次数组，并按消息 id 建位置表，
  追加与覆盖不再反复遍历历史。累加器只存在于单次调用；输入状态和之前返回的状态不被修改。
  删除消息或会话后按数组引用重建索引，保持与逐条 `reduce` 相同的结果。
- `thinkingTokensOf` —— 当前轮的近似思考进度；只随活事件存在，换轮或收工即清
- `mergeRateLimits` —— 账号额度的逐窗口纯合并；Store 归约和 Host 重连快照共用，
  空对象保留为明确清理信号
- `lanesOf` / `mainItems` / `laneItems` —— **主线与旁路的分流**。item 不拆表：
  带 `lane` 的照旧进 `items[threadId]`，分流放在选择器里。拆表的代价是 `owner` 的语义
  要跟着变（item 的增量、更新与撤回都要反查「它在哪张表里」），
  而回放老记录时那批 item 根本没有 `lane`。选择器分流是纯函数、可表驱动测、
  老记录天然全落主线
- `latestPlan` / `openPlan` / `stepProgressOf` / `visibleSteps` —— 两端共用的计划派生；
  只返回计划与进度数据，不返回任何展示文案

## 不拥有什么

- **不拥有任何 IO**。不落盘、不发网络、不起进程、不读时钟（时间来自事件的 `at`）。
- 不拥有命令。`Command` 是渲染层 → 宿主的方向，归约器只吃 `Event`。
- 不拥有渲染。它只回答「现在是什么状态」，不回答「怎么画」。
- 不拥有持久化格式。`@omni/journal` 自己决定怎么落盘。
- **不拥有引用稳定性**。`mainItems` / `laneItems` 每次调用都可能造新数组
  （`mainItems` 在一条都不带 `lane` 时原样返回，那是特例不是保证）。
  稳定化是渲染层的活——`App.tsx` 那句「`app.items` 不是 `app.itemsOf(thread.id)`：
  后者在空会话时每次渲染都造一个新数组，而 `Transcript` 的 memo 认引用」说的就是这个坑。

## 已知限制

- **状态全量常驻内存**，没有分页也没有淘汰。会话越长内存越大；
  落盘（`@omni/journal`）解决的是「重启不丢」，不解决这个。
  可运行 `node scripts/bench-replay.mjs` 测量合成历史的状态重建；它不包含磁盘 IO 与界面布局耗时。
- turn 反查只保留每个会话当前轮，终态立刻摘除；旧轮终态迟到时不会清掉新轮。
  item 更新从尾部反查，长会话正在生成的最后几条不再每帧从第一条开始扫描。
- `item.delta` 只对 `agent_message` / `reasoning` 与 **shell 工具的输出**生效，
  其余 item 类型的增量被忽略。shell 输出还有 8000 字符的**留尾**上限。
- 运行期收到分发表里没有的事件会**原样返回旧状态**，不报错也不记录。
  编译期是穷尽的（`Handlers` 是从 `Event["type"]` 映射出来的，漏一个编译不过），
  所以这条只在「宿主比渲染层新」时才会发生。
