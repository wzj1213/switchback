# @omni/web

omni 的**浏览器端**。手机和桌面浏览器共用一套界面：768px 以下一次看一屏，
以上并排两栏。产物是一堆静态文件，由主进程那侧的远程服务端送出去
（`apps/desktop/src/main/remote/`）。

它和桌面渲染层是**对等的两个客户端**，不是「主界面 + 一个远程视图」：
两端跑同一个归约器（`@omni/store`）、同一套补洞逻辑（`@omni/wire`）、
认同一条事件流的同一份编号。

## 拥有什么

- 四屏：配对、会话列表（**按项目分组**）、新建会话、会话正文
  （含审批卡、结构化问题卡、后台终端等待与输入记录、输入框）
- 引擎有未完成计划时，输入框上方常驻一行当前步骤；没有数据时整个不画
- 引擎报告长期目标时，输入框上方常驻原文、权威状态与预算使用；清空后整个不画
- Claude 报当前思考块近似 token 时，运行行实时显示；输出、换轮或收工立即清掉
- 侧问与后台任务旁路按出生位置插回正文：运行态、原生答案/错误、进度树与最终总结均随同一事件流更新；
  旧日志里的 `Thread.asides` 继续兼容显示
- **把老会话接回引擎**（`Reattach`）——手机上绝大多数会话是 detached 的，
  没有这个入口这一端就是只读的
- `transport.ts` —— WebSocket 连接：重连退避、心跳、断线续订
- `useRemote.ts` —— 事件流 → 视图状态，以及**确认**（桌面那条 IPC 不会丢，这条会）
- `auth.ts` —— 设备令牌的存取与配对
- `push.ts` + `public/sw.js` —— 推送订阅与通知展示（含 iOS 那三条硬前提），以及
  网络不可达时不带旧协议代码的独立离线页；在线导航始终读取当前入口

## 不拥有什么

- **不拥有传输层的规矩**。编号、按确认保留、分片、游标补洞全在 `@omni/wire`，
  两端共用一份——各写一份的下场是其中一份的补洞逻辑迟早和另一份不一样。
- **不拥有状态归约**。`Event → ViewState` 在 `@omni/store`，
  包括「补一条会话的历史」那条特殊路径（`reduceHistory`）——
  它的顺序规则两端都要一样，各写一份迟早对不上。
- **不拥有任何判定**。档位上限、命令校验、记忆范围收窄都在服务端
  （`main/remote/policy.ts`）。这一端拦不住任何东西——它跑在用户的浏览器里，
  改一行 JS 就绕过去了。**界面上的限制是提示，不是边界。**
- 不拥有引擎、进程、文件系统。这一端连一条路径都拼不出来。
- **不拥有推送的发送端**（那在主进程的 `remote/relay.ts`），只拥有订阅与
  service worker 那一侧的展示。

## 已知限制

- **只能在已经用过的项目里新建会话**。手机不该有文件浏览器，但它也不需要：
  每条会话都带着自己的 `cwd`，**已经在用的那些项目就是那份清单**。
  开一个**全新目录**仍然要去桌面——那件事本来就该在有键盘和文件系统的机器上做。
  （上一版这里写的是「不能新建会话」，理由是「要选目录」。那个结论是错的，
  已经改掉。）
- **不能改模型、切档位、接力、分叉。** 这些都是「开工前的决定」，
  而这一端的用途是「在外面看住它、放行它」。摆上去就要在小屏幕上重做一遍
  桌面那套选择器，收益很低。
- **记忆范围只有两档**（就这次 / 本会话）。`project` 级规则会落盘、跨会话生效，
  服务端也会把远程发来的 `project` 降成 `session`——所以这里干脆不摆那个选项，
  而不是摆一个点了会被悄悄改掉的按钮。
- **附件发不了**（贴图、拖文件）。要走一条新的上传通道，v1 没做。
- **首屏要下 Markdown 解析器**（实测 48.5 KB gzip，进独立的 vendor 块，改界面代码不重下；
  整个首屏 117 KB gzip）。换成手搓的轻量渲染器能省下这一块，代价是同一段回答
  在两端长得不一样——表格塌了、嵌套列表串行，那是让人**读错内容**的毛病。
- **没有页内查找、没有导出、没有 diff 的逐行视图。** 这三件在小屏幕上都要重新设计。
- **全量重建是分级的**，判据是**大小**（UTF-16 码元）不是条数：整份 192K 码元、
  单条 64K 码元封顶，超出的会话只发头，超长的会话只带尾巴，
  等你真的打开时再补（`watch` → `thread` 帧）。
  代价是**打开一条久没碰的会话时正文会晚一拍到**，而且**很长的会话看不到最开头**——
  往上翻不会自动加载更早的内容，那是分页，v1 没做。
