02 / 对齐

04 / 状态

这一条不是审美问题，是一条写了、跑了、但一个像素都没改变的规则。

05 / 思考行

收工之后，思考行是半句读不完的英文

跑着的时候这一行是对的：定高、只画最后一行、它长它的，下面纹丝不动。跑完之后它变成一段被齐着列宽切断的正文——占满一整行，信息量接近零，而且大概率是英文。

现在

// reasoning.ts
summaryOf(text, running=false) → 取第一行
// items.css
.think__line { white-space: nowrap; overflow: hidden; }   /* 齐着列宽硬切 */

仓库里其实已经有更合适的东西：reasoning.ts 的 headingOf()——模型自己给这一段起的 **小标题**。它现在只喂给状态行，折叠行没用上。

另外，硬切看起来像没渲染完，不像「还有」。这两种感觉差别很大：前者让人以为界面坏了。

改法。三行代码，一条 CSS。

// Reasoning.tsx —— 收工态先问模型自己怎么叫这一段
const summary = running ? summaryOf(text, true)
                        : (headingOf(text) ?? summaryOf(text, false))

/* items.css —— 右缘渐隐代替硬切 */
.think__line { mask-image: linear-gradient(90deg, #000 78%, transparent); }

短标题撑不满一行，这一行就从「一段被切断的正文」变回「一个标签」。跑动态完全不动——那部分本来就是对的。
