六套里我会怎么选

F 钛虹是我这一轮真会投的一票。它同时满足你点的三条，而且它的多色有出处——不是随手排的渐变，是一种金属的真实氧化色序。这一条在这个仓库里很重要：颜色一旦有出处，就不会被读成装饰。

A 极夜是「爆」这个字最到位的一套：安静态是灰的，爆开是一整片夜空。它也是唯一一个把星点用对了地方的——星点铺在浅底上是噪点，铺在深靛上才是星星。

D 墨金是最稳的一票，如果最后还想守住 tokens.css 那条「不用大面积彩色」：它整条几乎是墨，只有右端一截金。上一轮我把它排在第四，理由是「靠材质说话、而界面通篇是平的」——这一条我现在仍然认，但既然你要的就是质感，那它反而是最合适的。

B 曙光好看，我不投它只有一个原因：日出是个好消息，而这一档要说的是「这一轮开始烧钱了」。C 梦幻同理，更轻。E 玫瑰金和 D 撞在同一个位置（金属），两个选一个就够。

「爆」是怎么做的 —— 三件事，都是一次性的

① 一道白光扫过（720ms，从左扫到右，扫完就没）。② 柔光先撑大再收回（0 → 26px → 落到 16px 常驻）。③ 拇指弹一下（1 → 1.16 → 1）。

爆完之后留下的是静止的颜色，没有任何东西还在动——这一条是有意的：status.css 那句「一刻不停的动画会持续抢注意力」。原来那圈无限绕的扫光、⑥ 墨金那道无限循环的金、⑪ 落点那个无限脉冲，都是每分钟都在收租；一次性的爆只收一次。

往回拖一档就灭，再拖回去就再爆一次。它不是「播过一遍就完了」的开场动画，是这一档的状态转换。

prefers-reduced-motion 下：扫光、柔光撑大、拇指弹跳、星点闪烁全部不出现，颜色和柔光留着——降级之后信息一个字不丢。
